          Dithering

          ? Default hands the frame to the driver, which blends its two palettes by the saturation value and dithers once. The other two convert here and pass a P image so the driver copies it untouched: Palette matches the measured inks with Floyd-Steinberg, Oklab matches them by perceptual distance and sharpens edges first. Compare them with Refresh preview before saving.
          ? Range 0 - 1, step 0.1. This is a palette blend, not photo saturation: 0 quantises to pure primaries (more punch, cruder), 1 to the panel's measured inks (softer, more faithful). 0.5 is Pimoroni's default. Lower it if colours look dull.
          ? The inks the dithered output is matched against. Driver uses the panel's measured colours, Pure uses the theoretical primaries, Custom lets you paste the values you measured yourself.
          ? Seven hex values in the driver's ink order: black, white, green, blue, red, yellow, orange. They are the colours the output is matched against, so copy the ones you measured on your panel.

          Tone

          ? Range 0.25 - 2.0, step 0.05, 1.0 leaves the photo alone. Moves the whole frame lighter or darker before the panel picks inks. Raise to 1.1 - 1.2 when a photo looks grey; go back to 1.0 if whites start to glare.
          ? Range 0.25 - 2.0, step 0.05, 1.0 leaves the photo alone. Spreads light and dark before ink selection, which is what separates similar tones. 1.2 - 1.4 usually helps photos; above 1.5 shadows start to block up.
